Code switching is a change of spoken language within an utterance or between turns. Gladia can transcribe these changes when code switching is enabled. Provide a focused list of expected languages and inspect the detected language in the transcript output. Transcription preserves the spoken content, while translation is a separate feature.

<Note>
  For best accuracy and latency, provide a small set of expected languages.
  Avoid listing dozens of similar languages.
</Note>

## How to use code switching ?

Enable code switching in the session configuration:

```json
{
  "encoding": "wav/pcm",
  "sample_rate": 16000,
  "bit_depth": 16,
  "channels": 1,
  "language_config": {
    "languages": ["en", "de", "fr"],
    "code_switching": true
  }
}
```

When enabled, transcript messages include the detected `language` per utterance and per word. Use the [`transcript` message](/api-reference/v2/live/message/transcript) schema for details.

<Warning>
  **Do not enable `code_switching` with an empty `languages` list.** When no
  languages are specified, the language detector evaluates every utterance
  against 100+ supported languages, leading to frequent misdetections -
  especially between similar-sounding languages.
</Warning>

## Recommendations

- Limit the number of languages to those you expect.
- Combine with [custom vocabulary](/chapters/audio-intelligence/custom-vocabulary) per language for domain terms.
- Use [supported languages](/chapters/language/supported-languages) to pick valid ISO 639-1 codes.
- Check [model selection](/chapters/introduction/models) for language and code-switching availability by model. Live transcription uses Solaria-1.
- Multiple languages or code switching can reduce [partial transcript](/chapters/live-stt/features/partial-transcripts) accuracy — keep the expected-language list focused.
- Supported languages describe coverage, not guaranteed accuracy on your production audio. Review [async benchmarks](https://www.gladia.io/competitors/benchmarks) with their model and dataset limits, then evaluate with the [blind comparison tool](https://www.gladia.io/compare-stt-apis) and [pricing](https://www.gladia.io/pricing).
